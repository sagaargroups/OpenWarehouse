## 3. The 4 Non-Negotiable Operational Principles

These four tenets are permanent brand commitments, enforced across every client engagement:

### 1. You Own Everything
Domains, hosting accounts, repositories, and source files are registered in the client's name from Day 1. If a client ever chooses to leave, leaving must be administratively boring. No hostage code, no proprietary lock-in.

### 2. Scope is Written Down
What is included, what is not, and what changes cost — agreed in writing before work begins, never negotiated after. Clarity prevents resentment.

### 3. We Say When Something is a Bad Idea
Including when it is the client's idea, and including when agreeing would be easier and more profitable. Real operators protect the commercial outcome, not their client's ego.

### 4. No Invented Proof
No stock testimonials, no logos of companies we did not work with, no vanity metrics we cannot source. If a section of our site or portfolio is empty, it is empty because it is true.

## 4. The Sovereign Architecture Narrative

Why D2C With AHrik builds on Astro + Cloudflare Edge instead of legacy CMS platforms (WordPress/Webflow):

- **Unhackable Security:** Zero database exploits, zero WordPress plugin vulnerabilities.
- **$0.00 / Month Hosting Overhead:** Edge compiled delivery eliminates bloated monthly hosting charges.
- **100/100 Core Web Vitals:** Instant sub-50ms global response times maximize conversion rates on every paid traffic dollar.
- **Pure Code Sovereignty:** Pure TypeScript, Git version-controlled, owned 100% by the client forever.
